# Spec: attention feed

- One feed for everything that needs the user's attention, across the enabled projects; items are entities of any type
- The user verifies, approves or sends back; a reaction can be a change request, a split or new entities
- Nothing changes unattended: the approved state is the system
- Counters above the cards: entities by state, verified, unverified and each sync state
- Ranked by what to do now for the best product and an optimal journey: impact on the product, on the timeline, and how much it unlocks
- Features, optimizations, refactorings and explorations compete on one scale; no project priority
