# Momentum

The harness that boosts the performance of the work done around a project: the single entry point between the user and that work, for every workspace on the dedicated machine.

- Three ways in: the attention feed, a chat tool, and direct exploration of the entities
- Automations run in the background per project and prepare work ahead of time
- Nothing changes unattended: every change passes the feed as an entity before it counts
- Manages itself: this repository is one of its workspaces
- Single user by design; 5 to 20 enabled projects expected at once
