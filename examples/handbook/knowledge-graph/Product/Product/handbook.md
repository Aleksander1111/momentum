# Brightwater team handbook

The written source of truth for how Brightwater Studio, a 30-person design studio, works: if it is not in the handbook, it is not a rule.

- Covers onboarding, remote work, leave and meetings
- Anyone proposes changes by pull request; People Ops reviews policy changes, team leads the rest
- Merged changes are announced in #general the following Monday
- Superseded policies are kept in `archive/` for reference only
